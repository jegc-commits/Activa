# Política de privacidad — ACTIVA

ACTIVA funciona completamente en el dispositivo. No envía datos personales a servidores externos.

- Los datos (usuarios, talleres, asistencias, avisos) se guardan en una base de datos SQLite local.
- No hay anuncios ni telemetría.
- La variante FOSS no incluye Google/Firebase; el login es únicamente local (usuario y contraseña con hash SHA-256 + sal).
- La recuperación de contraseña por correo solo se activa si se configura un servicio externo (EmailJS); por defecto el código se muestra en pantalla.
